MODIFIED DATASET PACK - for comparison only
==========================================
Made on 2026-11-20 from the original Project_01 pack. Same folders, file names and columns.

What changed
- data/main.csv: the same 395 real UCI Student Performance records; NEW stratified
  train/validation/test split (seed 2026). Counts stay 276 / 59 / 60; 191 records changed split.
- data/images.npz: a different real MNIST subset (the 5,000 MNIST samples bundled with the
  mlxtend Python package), balanced: 160 train / 40 validation / 50 test images per digit.
- data/feedback.csv: 30 NEW authored English comments (10 positive, 10 negative, 10 neutral)
  with reference labels written by meaning. Not real student responses.
- data/example_inputs.csv, data/image_manifest.csv, sample_images/, data/meta.json: regenerated.

Unchanged
- data/topic_keywords.json, data/prompt_test_cases.json, nltk_data/, source_notices/
